# Simple Interest Calculator

This project contains a simple bash script to calculate simple interest based on user input.

## Formula
The formula used for calculating simple interest is:
**I = P * R * T**

Where:
*   **I** = Simple Interest
*   **P** = Principal amount
*   **R** = Rate of interest (per year)
*   **T** = Time period (in years)

## How to Use
1. Clone this repository.
2. Run the script `simple-interest.sh`.
3. Enter the Principal, Rate, and Time when prompted.

## Example
If Principal = 1000, Rate = 5%, Time = 2 years:
Interest = 1000 * 0.05 * 2 = 100
